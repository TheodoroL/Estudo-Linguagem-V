# Estudos sobre a linguagem V

Olá, pessoal! Tudo bem com vocês?

Neste repositório, vocês vão acompanhar minha jornada de estudos com uma linguagem que achei bastante interessante: [V](https://vlang.io/).

Conheci a linguagem e gostei bastante da sua proposta, principalmente pela simplicidade da sintaxe e pela forma como ela busca manter o código claro e direto.

## Sobre a linguagem

V é uma linguagem de programação compilada e estaticamente tipada, semelhante a Go e influenciada por linguagens como:

- Oberon
- Rust
- Swift
- Kotlin
- Python

Uma das características que mais me chamou atenção é a simplicidade da linguagem. A própria documentação do V destaca a proposta de escrever código simples e claro, com o mínimo de abstrações possível.

Apesar de sua simplicidade, V oferece recursos suficientes para desenvolver diferentes tipos de aplicações.

## Sobre este repositório

A ideia deste repositório é documentar minha jornada de aprendizado com V.

Vou utilizar principalmente a [documentação oficial da linguagem](https://docs.vlang.io/introduction.html) como referência, mas os conteúdos apresentados aqui serão escritos com minhas próprias palavras e acompanhados de exemplos práticos.

O objetivo não é substituir a documentação oficial, mas criar um material de apoio baseado naquilo que estou aprendendo durante meus estudos.

> Este repositório está em constante desenvolvimento. Conforme eu avançar nos estudos, novos conteúdos, exemplos e desafios serão adicionados.

## Como os estudos serão organizados

A organização dos estudos seguirá, de maneira geral, a estrutura apresentada pela documentação oficial do V.

Cada tópico terá seu próprio diretório ou arquivo, contendo exemplos e anotações sobre o assunto estudado.

A ideia é que o README funcione como um índice para facilitar a navegação pelo conteúdo.
